### Official SDKs

| Language | Repository | Install |
| --- | --- | --- |
| Node.js / TypeScript | [reelspan-node](https://github.com/Reelspan/reelspan-node) | `npm install reelspan` |
| Python | [reelspan-python](https://github.com/Reelspan/reelspan-python) | `pip install reelspan` |

Both retry safely, never publish a post twice, upload large files in parts and verify webhooks.

### For AI agents

Reelspan has a built-in MCP server at `https://api.reelspan.com/mcp`: connect it to Claude, Cursor or any MCP client
and publish from a chat.

### Security
